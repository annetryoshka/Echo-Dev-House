# Echo Dev House

> *"Ingeniería de software predecible, soluciones tecnológicas confiables."*

Repositorio oficial del proyecto de consultoría en ingeniería de software. 
Este espacio centraliza la documentación institucional, los diagramas de arquitectura, el modelado de bases de datos y el código fuente del sistema desarrollado bajo estándares internacionales de calidad.

---

## Equipo de Trabajo y Roles

La consultora está operada por un equipo multidisciplinario bajo una estructura jerárquica gestionada:

*   **Andrea Narváez** — *Directora de Proyecto y Analista de Sistemas*
    *   Gestión de proyectos en Jira, levantamiento de requerimientos (SRS bajo norma ISO/IEC/IEEE 29148) y comunicación con stakeholders.
*   **Adriana Pando** — *Arquitecto de Software y Desarrollador Backend*
    *   Diseño técnico mediante modelos C4, modelado y optimización de base de datos relacional (**SQL Server**) y desarrollo de la lógica de negocio (**Spring Boot**).
*   **Jorge Tito** — *Especialista en QA (Calidad) y Desarrollador Frontend*
    *   Desarrollo de la interfaz de usuario, control de calidad bajo norma ISO/IEC 25010, planes de prueba y automatización.
